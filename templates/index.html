About Project

AgriSight – Smart Harvesting Robot

AgriSight is an intelligent robotic system designed to automate fruit harvesting using Artificial Intelligence and Computer Vision.

The system uses YOLOv8 for real-time fruit detection and a robotic arm controlled by Raspberry Pi to pick fruits efficiently without damage.

It reduces labor dependency, improves harvesting speed, and enables smart farming solutions.
