AgriSight – Smart Harvesting Robot

This system is an AI-based autonomous fruit harvesting robot designed to automate the process of fruit picking using computer vision and robotics. The system uses the YOLOv8 deep learning model to detect fruits in real-time and classify them based on ripeness.

The robot is powered by a Raspberry Pi 4 and is equipped with a camera to capture live images from the agricultural field. Based on the detection results, the system identifies ripe fruits and sends commands to the robotic arm for harvesting.

To use the system, the robot continuously scans the environment using the camera. Once fruits are detected, the model processes the image and determines whether the fruit is ripe or unripe. The robotic arm then moves precisely to pick only the ripe fruits, ensuring minimal damage and efficient harvesting.
